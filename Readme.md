# PROYECTO DE APRENDIZAJE AUTOMÁTICO

## Segmentación mediante detección de patrones en población adulta en el consumo de psicofármacos con fines terapéuticos

### Descripción

El presente proyecto tiene como objetivo identificar patrones de consumo de psicofármacos en población adulta mediante técnicas de aprendizaje automático.

A partir de la integración y procesamiento de diferentes conjuntos de datos, se busca caracterizar perfiles de consumo y analizar variables sociodemográficas asociadas al uso de medicamentos psicotrópicos con fines terapéuticos, tales como ansiolíticos, hipnóticos, sedantes, antidepresivos y otros psicofármacos de uso frecuente.
